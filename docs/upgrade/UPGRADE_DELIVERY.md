## 本轮交付功能

- **账号与空间**：密码登录、一次性邀请注册、已有账号加入团队、每人私人空间、团队创建、成员及角色管理、所有权转移、邀请撤销、退出、改密码、管理审计。私人内容服务使用独立 SQLite 和文件根，每个请求在服务器验证权限；没有公开自助注册。
- **私人内容主动分享**：先预览原文、目标及引用附件，再确认复制。保留原稿，团队副本重新分配笔记/附件 ID；确认前内容变化需重预览。回执持久化，重复确认复用结果；不确定中断保留核查证据，不盲目重放。
- **保存与交互**：继续保留前两轮文件身份和草稿保护；新增 Task 条件保存、真实用户事件归属、空间/角色提示、会话失效保稿、统一弹层键盘和焦点管理、已删除任务单项恢复；门户隔离跨登录、跨团队、旧请求和分享操作的迟到响应。
- **检索可用性**：未配置或远端失败时，本空间关键词搜索仍可用，明确告知只覆盖笔记正文与附件文件名；Processing 局部失败保留主库结果并持续提示。评测工具保留 remote/local-keyword/partial 和覆盖率，避免把降级命中当成完整远端检索成功。
- **数据保全与迁移**：清点、停写备份、原字节/SQLite逻辑校验、源漂移检测、新目录恢复、显式绑定本人私人空间。整套协作备份包含身份、所有空间、回执；恢复撤销会话/邀请，核对成员后才解除启动门禁。
- **运维**：独立 loopback 入口、离线账号找回、实际 tarball 集成验证，部署与备份操作指南。已有单人入口仍为兼容模式，协作上线必须替换整个 `/pkw` 代理路径并关闭旧入口。

## 服务器报告后的同步修复

服务器 DSH 报告删除提示可能被较旧同步清掉，导致映射停留在 `synced`，未产生远端删除意图。选择先修再上线；第三轮一次通过不能关闭这个缺陷，也不能手动安装绕过部署测试门禁。生产仍为旧版、迁移演练已通过等信息来自 DSH 回报，本轮未连接或修改生产。

本机在未修改服务的 `2892a70` 上新增三条确定性回归，三条均以 `synced` 对 `deleted` 断言失败：新删除发生在清理之前、清理写入等待期间，以及事件已提交但目录投影尚未可见。修复同时包含：

- 所有 dirty 簿记使用同一实体的短写入队列；收到新提示时立即使当前同步轮次不能清掉它。队列不等待远端 HTTP，`drain` 等待已经收到的提示落库。
- 保留事件提示，并监听宿主 `domain/changed` 的持久化后目录通知，避免只读到旧目录；挂起操作保留事件修订号，未终结意图不能被无操作路径清除。
- 启动和全量核对补回已删除目录记录的提示；已完成的同一远端删除不重复创建意图。解析状态刷新与同步按实体串行，避免旧映射覆盖新删除。
- 恢复时确认远端旧编号是否仍存在：只有明确 404 才重建，离线继续待重试；保留 A→B 丢响应→A 的未知更新恢复。

本轮实际证据（忽略目录 `.pkw-evidence/dirty-race-*`）：TypeScript 通过；全仓 **490 项 Vitest + 79 项 Node 工具测试通过，5 项真实 WeKnora 集成跳过**；同步文件 60 项通过，并在独立进程中重复 10 轮全部通过（每轮含 15 次真实定时器删除收敛）。增加的 10 项回归含实际卸载/重开服务、目录延后、修订号为零的派生内容提示、完整远端删除及笔记/附件恢复。测试使用真实本机 HTTP 与 SQLite、合成资料，远端仍是受控模拟服务。

构建复验：10 包、70 个输出文件两次哈希一致，陈旧输出移除。十个 tarball 在无 PKW 源码的临时 profile 实际安装通过，普通 Node 导入/声明消费/Vditor，以及单人入口、协作登录/权限/保存/分享、独立监听重启/离线账号恢复的真实 HTTP 验证均通过。独立审查检查了所有 dirty 写入口、锁顺序、恢复路径及宿主通知语义。宿主仍为下面列出的本机 Harness，目标服务器必须用自身实际 Harness 再跑完整门禁；跨进程在事件日志与目录两次写入之间的断电窗口、物理 purge 路径不属于本轮新增回归的承诺。

服务器继续步骤见 [竞态部署补充交接](../weknora-sync-race-handoff.md)。必须保全服务器转换器和两个测试文件补丁，用新精确提交重新构建并采用未占用的不可变发布版本；不能继续安装旧候选 `0.1.1-pkw.1` 或覆盖其已发布产物。实际资料、配置和内容全部保留，旧资料导入原所有者私人空间。

## 明确保留的限制

1. 生产服务方式、实际数据布局/域版本、宿主源码、手改 UI 尚未清点。未知旧 schema 必须先保全，再按实际格式补转换并演练，不能直接改版本号。没有目标回执就不宣称旧服务器已无损迁移。
2. 五项真实 WeKnora 集成测试需要真实服务和凭据；合成评测和本地关键词不证明真实语义相关性、OCR、摘要或附件全文提升。
3. 单进程网关锁和域内队列限制同时写入者；外部直接编辑文件不是受同一事务协调。文件、数据库、远程索引及分享复制不是一个跨介质原子事务。运行中不可另启实例写同一根。
4. 登录采用账号密码与邀请；未提供 SSO/MFA/邮件找回、逐笔记ACL、实时多人同文档合写或组织目录。权限是应用层隔离，运维人员仍可读取磁盘/备份。
5. 本机15账号测试验证功能，不承诺真实服务器容量；完整手机真机、读屏、输入法和全部Vditor操作仍需对应实测。
6. 生产开始接收新写入后，不能直接用旧备份覆盖。回退包与回退资料是不同动作，先备份新写入并分析差异。
