# PKW 产品与项目升级计划

更新：2026-10-02。早期审查基线为 `b379818c7ee77d365fb3b0c682a2743a71aa098e`，当前表格描述随后累计实现，不把旧基线的测试数量当成本次结果。完整统计与最终包/浏览器/CI/生产结论由协调者维护在 [UPGRADE_DELIVERY.md](UPGRADE_DELIVERY.md)。

用户已确认：电脑与手机的日常体验都需要；首批约 **15 人**；采用“每人私人空间 + 团队共享空间”；**服务器旧资料全部先归本人私人空间**；入口为 `https://ddmind.duckdns.org/pkw`。这些决定已进入实现，不再列成待询问。目标机器的实际存储、停启方式、历史手改和真实语料仍需证据，网址本身不能替代它们。

## 目标、范围和当前结论

产品主线是“登录选空间 → 保存资料 → 整理笔记与附件 → 查找知识 → 创建待办 → 删除与找回 → 明确复制给团队”。先保证内容、身份与授权不受误操作和异步响应破坏，再用真实问题验证检索与性能。

个人可靠性修复、多人登录/角色/空间、邀请、复制、检索降级、账号恢复、旧数据保全和导入工具已形成源码及本机不同层级的验证。协作全根备份恢复 gate 也已由开发团队报告工具与真实 Harness 专项通过；协调者继续最终安装包与浏览器。**这仍不是服务器已升级、15 人容量达标或真实检索质量提升的结论。**

“本地优先”是服务端 Note/Attachment/Task 不依赖 WeKnora 才能读写。新协作入口为 `/pkw/spaces/<id>/api`；浏览器与 PKW 服务器完全断网时仍不能承诺保存成功。手机正文继续 read-first，任务和搜索按已开放能力操作。

## 九条旅程与证据分层

[ACCEPTANCE_MATRIX.md](ACCEPTANCE_MATRIX.md) 保留 J1 首次打开、J2 编辑、J3 冲突、J4 整理、J5 附件、J6 检索、J7 任务、J8 回收站、J9 手机与键盘的逐步操作。每条都要区分源码、自动化、真实浏览器、实际安装包、目标服务器与真实外部服务。多人 C1–C6 叠加验权与旧数据保全，不能由双窗口编辑通过推导其全部完成。

开发团队负责 canonical、任务与保全/恢复；设计交互团队负责编辑、弹窗、导航、角色和门户；产品项目团队负责边界、独立验收、检索评测；协调者负责跨团队整合、包/浏览器、CI/发布与最终证据。定向测试是整合测试的子集，不能相加冒充总数。

已关闭的独立审查问题包括：旧路径复用误删、编辑/表格/脚注旧响应写错对象、Task 新草稿被旧保存确认清除、附件详情乱序、Inbox null 过滤、凭据 provider 无限等待、归档任务恢复后不可达、同步 completed 被误判 pending、冲突重读失败丢稿、未知 identity DB 写前校验和慢请求期间失效会话复验。它们分别有真实文件、实际函数、服务或 HTTP 证据；具体浏览器覆盖仍按矩阵列明，不合并成笼统“全面通过”。

## 真正仍需部署方或用户提供的三类输入

1. **真实检索问题与预期资料**：例如“搜项目报价，应当找到哪份 PDF”。可提供脱敏问题和预期文件，不需把整库传给新服务；用于建立真实金标准，避免只优化样例分数。
2. **目标服务器的只读环境与可恢复备份证据**：入口已知。部署方需要确认实际数据/配置/手改 UI、服务停启和代理路由；工具负责清点，不要求用户自己猜数据库位置，也不要求贴 token。没有这些，不能证明升级保留了线上旧资料。
3. **常用手机/浏览器及资料规模**：例如“iPhone Safari，几千篇笔记和 PDF”。人数约 15 已知；设备用于真机验收，资料量用于容量样本。这些只影响相应验收，不阻断已可独立完成的源码工作。

## 冻结边界与文档维护

- Note Markdown、Attachment 二进制、Task Store 各自 canonical；WeKnora 是解析、索引、检索和派生内容，不成为第二套权威数据。
- 原对象 NoteId/AttachmentId/TaskId 保持稳定；复制是新对象的新 ID。路径只表示位置，Folder 仍为派生目录。
- 业务导航和授权不依赖 remote ID；请求体不能切换已授权空间。
- 服务端本地读写独立于 WeKnora；手机正文 read-first；浏览器断网不承诺可写。
- 不自动启动 DOCX canonical、跨空间实时引用、附件全文物化到 Main 或新的收费外发服务。
- 旧 HANDOVER、历史失败和早期测试数字是快照，不是当前结果。实际漂移已在本轮核对；权威交付由 UPGRADE_DELIVERY 更新，长期欠缺仍登记 DEBT，不能因新增源码就把整份计划全部改成完成。
